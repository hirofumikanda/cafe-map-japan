# cafe-map-viewer Specification

## Purpose

MapLibre GL JS v6を用いてOpenStreetMap Standard背景地図上に日本全国のカフェ・喫茶店POIを表示し、クリックによるプロパティ確認とチェーン店の視覚的識別を可能にするWebマップフロントエンド。

## Requirements

### Requirement: 背景地図の表示
システムはMapLibre GL JS v6を用いて、OpenStreetMap Standardの背景地図を表示しなければならない(SHALL)。

#### Scenario: 初期表示で背景地図が読み込まれる
- **WHEN** ユーザーがマップページを開く
- **THEN** OpenStreetMap Standardの背景タイルが表示された状態でマップが初期化される

### Requirement: カフェ・喫茶店POIのシンボルレイヤ表示
システムは配信されているPMTilesをソースとして読み込み、カフェ・喫茶店POIをシンボルレイヤとして地図上に表示しなければならない(SHALL)。PMTilesの生成ズーム範囲(z10-14)を外れるズームレベルでは、オーバーズームまたは非表示によって適切に扱わなければならない(SHALL)。

#### Scenario: ズーム範囲内でPOIシンボルが表示される
- **WHEN** ユーザーが地図をズームレベル10から14の範囲内で表示する
- **THEN** 表示範囲内のカフェ・喫茶店POIがシンボルとして描画される

#### Scenario: 最大ズームを超えてもPOIが表示され続ける
- **WHEN** ユーザーが地図をズームレベル14を超えて拡大する
- **THEN** z14タイルのオーバーズーム表示によりPOIシンボルが表示され続ける

#### Scenario: 最小ズーム未満ではPOIが表示されない
- **WHEN** ユーザーが地図をズームレベル10未満に縮小する
- **THEN** カフェ・喫茶店POIのシンボルレイヤは表示されない

### Requirement: POIクリック時のプロパティポップアップ
システムはユーザーがカフェ・喫茶店POIのシンボルをクリックした際、そのPOIが保持する各種プロパティ(店名・ブランド・住所等)をポップアップとして表示しなければならない(SHALL)。

#### Scenario: POIシンボルをクリックするとポップアップが表示される
- **WHEN** ユーザーが地図上のカフェ・喫茶店POIシンボルをクリックする
- **THEN** クリックしたPOIのプロパティ(店名を含む)を表示するポップアップが地図上に表示される

#### Scenario: 何もない場所をクリックしてもポップアップは表示されない
- **WHEN** ユーザーがPOIシンボルが存在しない地図上の地点をクリックする
- **THEN** ポップアップは表示されない

### Requirement: チェーン店のアイコンによる視覚的識別
システムはPOIのブランド識別情報(`brand`・`operator`・`name`等)に基づき、既知のチェーン(例: ドトール、ベローチェ)に該当するPOIを専用アイコンで表示しなければならない(SHALL)。既知チェーンに該当しないPOIは汎用アイコンで表示しなければならない(SHALL)。

#### Scenario: 既知チェーンのPOIが専用アイコンで表示される
- **WHEN** ブランド識別情報が既知チェーン(例: ドトール)に一致するPOIを表示する
- **THEN** そのPOIは当該チェーン専用のアイコンで描画される

#### Scenario: 未分類のPOIが汎用アイコンで表示される
- **WHEN** ブランド識別情報がどの既知チェーンにも一致しないPOIを表示する
- **THEN** そのPOIは汎用のカフェアイコンで描画される
